# xtask merge et origin-check (T3). Toute modification est elle-même sensible (tools/ci/).

# Format : une entrée par ligne ; « # » commente jusqu'à la fin de la ligne.
#   dossier/               tout fichier sous ce dossier (préfixe)
#   fichier                ce fichier exactement
#   section:<motif>        section d'un Cargo.toml (toute crate), « * » pour un segment ou plus
#   cargo-lock:new-crate   Cargo.lock qui ajoute une crate (nom absent de la base)
#   cargo-toml:sources     Cargo.toml dont une ligne ajoutée ou retirée touche [patch, [replace,
#                          git =, registry =, branch =, tag = ou rev = (AS-23 point 4)
#   cargo-lock:source-change  Cargo.lock où une crate de la base change de source
# Les chemins se comparent sans tenir compte de la casse (B1).
